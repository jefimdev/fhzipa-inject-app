    bloco em andamento).
  - A desinstalacao com dados do usuario presentes: o comportamento de
    preservar os dados foi conferido pelo codigo, nao por execucao.
  - O caminho de atualizacao automatica (o manifesto latest.json ainda
    aponta para o instalador NSIS).

  ROTEIRO MANUAL PARA O USUARIO CONCLUIR
  ---------------------------------------
  1. Instale o Visual Studio Build Tools (carga "Desenvolvimento para
     Desktop com C++") se ainda nao estiver instalado.
  2. cd ..\fhzipa-inject-app && npm run tauri build
  3. cd ..\instalador fhzipa && powershell -ExecutionPolicy Bypass -File
     scripts\build.ps1
  4. .\out\publish\FHZIPA_INJECT_Setup.exe --preview
     Confira as 8 telas, a faixa de previa, o teclado (Enter e Esc).
  5. .\out\publish\FHZIPA_INJECT_Setup.exe --install-dir="$env:TEMP\FHZIPA-MANUAL"
     Confira: os arquivos, o atalho, "Aplicativos instalados" e a abertura
     do aplicativo.
  6. $env:TEMP\FHZIPA-MANUAL\desinstalar.exe
     Responda "Sim" e confirme que a pasta sumiu e que o aplicativo
     continua em "Aplicativos instalados" como desinstalado.
  7. .\out\publish\FHZIPA_INJECT_Setup.exe
     Aceite a autorizacao do Windows e repita os passos 5 e 6 no caminho
     padrao.
