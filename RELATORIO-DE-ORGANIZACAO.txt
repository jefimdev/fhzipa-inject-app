7. ERROS PREEXISTENTES ENCONTRADOS (NAO CORRIGIDOS)
================================================================================

Estes pontos ja estavam no repositorio antes desta tarefa e NAO foram
alterados, porque corrigi-los mudaria o processo de instalacao/publicacao
(que esta fora do escopo desta tarefa). Estao registrados para revisao:

  1. CI com bun, projeto com npm.
     .github/workflows/build.yml roda "bun i --frozen-lockfile", mas o
     repositorio passou a usar npm (package-lock.json presente,
     bun.lock removido pelo usuario, e o proprio tauri.conf.json chama
     "npm run dev" e "npm run build").
     Impacto provÃ¡vel: o "--frozen-lockfile" falha sem o bun.lock, entao o
     workflow do build deve quebrar no proximo push, a nao ser que o bun
     gere um bun.lock novo durante o proprio job (o que tornaria a
     instalacao nao reproduzivel).
  2. Build Nix tambem depende do bun.lock.
     flake.nix usa bun2nix (bun2nix -o bun.nix a partir do bun.lock).
     Sem o bun.lock, o "nix build" quebra.
  3. Scripts bump-* usam bunx.
     package.json: "bump-patch": "bunx tauri-version --no-git --no-lock patch".
     Precisam de bun instalado, ou trocar por npx.
  4. A interface nao roda em navegador comum.
     Nao e um bug do projeto: e o desenho do Tauri. As chamadas invoke()
     falham fora do aplicativo. Registrado no guia para nao confundir
     ninguem.
  5. Chaveiro do Windows como dependencia do ambiente.
     Sem o Visual Studio Build Tools (C++) e o WebView2 Runtime, o
     aplicativo nativo nao compila nem roda nesta maquina (veja secao 10).
